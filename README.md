# SMP Card Assistant

Программа для подготовки шаблонов карт вызова СМП и заполнения соответствующих полей в медицинской системе через расширение Chrome.

## Компоненты

- **desktop/** — Windows-приложение для создания и редактирования шаблонов, включая структурированные поля ProMed.
- **extension/** — расширение Chrome Manifest V3. В папке сейчас находится расширение v0.2.0 с базовым заполнением и дополнительными полями осмотра.
- **templates/** — примеры шаблонов без реальных персональных данных.
- **schemas/** — схема и проверка формата JSON.
- **PROJECT_CONTEXT.md** — актуальное состояние проекта и принятые решения.

## Принципы

- Шаблоны хранятся локально в JSON.
- Поддерживаются отдельные текстовые заготовки и шаблоны целой карты.
- Медицинские сведения, требующие индивидуальной оценки, не выдумываются и не подставляются автоматически без подтверждения.
- Расширение не нажимает кнопку сохранения карты.
- Не добавлять сервер, облачную синхронизацию или передачу данных пациентов без отдельного согласования.

## Текущий проверенный прототип v0.1.0

Путь: `extension/`

- Выбор причины обращения из справочника ProMed.
- Заполнение полей «Жалобы» и «Анамнез».
- Проверка наличия известных полей на открытой карте.
- Не сохраняет карту автоматически и не отправляет содержимое карточки на внешние серверы.
- Пользователь подтвердил стабильную работу заполнения.

Диагноз пока только обнаруживается, штатный выбор из справочника ещё не реализован. Перед сохранением карты нужно визуально проверить подставленные значения и сохранить её вручную.

## Статус

Рабочий тестовый прототип интеграции с ProMed зафиксирован в GitHub. Windows-редактор теперь содержит структурированные поля ProMed: сведения о вызове, общий и неврологический осмотр, дыхание/сердце/живот, жизненные показатели до и после помощи, манипуляции, исход и рекомендации. Экспорт JSON включает эти значения; расширение импортирует их и переносит в соответствующие контролы popup. Перед заполнением ProMed нужно проверить значения. Сборка Windows после этого изменения требует проверки в GitHub Actions.


## Дополнение к версии 0.2.0: неврологический статус и кожные покровы
В popup добавлены элементы для сознания, менингеальных знаков, зрачков, нистагма, анизокории, реакции на свет, большого родничка, корнеальных рефлексов, симптома Белоглазова, видимых повреждений, кожных покровов, акроцианоза, мраморности и отёков. Добавлены текстовые поля описания повреждений и отёков. Реальная работа каждого поля требует проверки на учебной карте; автосохранение отключено.


## Перенос структурированных полей между Windows и расширением

- Windows-редактор сохраняет дополнительные значения в `extensionFields` внутри каждого шаблона.
- Расширение импортирует `extensionFields` и переносит выбранные значения в одноимённые элементы popup.
- Пустые текстовые поля не заменяют уже введённый текст в popup; селекты «Не менять» не изменяют значения карты.
- Числовые значения не следует задавать универсально: в шаблон вносятся только намеренно сохранённые значения, которые нужно проверить перед применением.
- Заполнение карты и её сохранение остаются разными действиями. Расширение не нажимает «Сохранить».
