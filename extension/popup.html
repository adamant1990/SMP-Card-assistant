Осмотр: дыхательная система

Сердце и пульс

Выбирай по одному варианту в каждой группе. После заполнения проверь оба значения в ProMed. Выбери нужные пункты; пустой список не меняет поле. Можно выбрать несколько пунктов.

Язык

Выбирай по одному варианту в каждой группе. Если кнопка не будет найдена по точной подписи, расширение оставит поле без изменений.

Характеристика живота, болезненность и печень выбираются по подписи кнопок внутри своей группы. Если точная группа не найдена, значение не изменяется.

Помощь и показатели после манипуляций

Артериальное давление после манипуляций

Показатели после манипуляций заполняются независимо от показателей при осмотре. Пустые поля не меняют карточку.

Манипуляции

Отметь манипуляции, которые нужно добавить
Выбирай только фактически выполненные манипуляции. Для этих пунктов ProMed использует триггеры внутри таблицы, поэтому сначала проверь на учебной карте. Не запускай повторно с теми же пунктами, пока не убедишься, как сайт обрабатывает повторное нажатие.

Доставка и завершение вызова

Выбирай только подтверждённые по фактическому состоянию пациента значения. Пустой выбор «Не менять» оставляет поле без изменений.
