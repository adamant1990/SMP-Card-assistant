SMP Card Assistant — тестовая версия 0.1.0

ПРОВЕРЕНО ПОЛЬЗОВАТЕЛЕМ
- Выбор причины обращения из справочника ProMed.
- Заполнение полей «Жалобы» и «Анамнез» текстом из расширения.
- Пользователь сообщил, что заполнение работает стабильно, в том числе на другой карточке.

ВАЖНО
- Это тестовый прототип, не готовая медицинская система.
- Расширение не нажимает кнопку сохранения карты и не отправляет данные автоматически.
- Код не содержит сетевых запросов и не передаёт данные наружу.
- Сначала тестируйте на учебной/тестовой карте и вручную проверяйте результат.

УСТАНОВКА В CHROME
1. Откройте chrome://extensions
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение».
4. Выберите папку extension этого репозитория, где находится manifest.json.
5. Откройте ProMed и карту вызова, затем нажмите значок расширения.

ТЕСТ
1. Нажмите «Проверить поля ProMed».
2. Выберите причину обращения.
3. Введите текст жалоб и/или анамнеза и отметьте соответствующие флажки.
4. Нажмите «Заполнить выбранные поля».
5. Проверьте каждое поле визуально. Сохранение карты выполняйте вручную.

ТЕХНИЧЕСКИЕ ПОЛЯ
- Причина обращения: input[name="cmpreasonnew_id"], компонент Ext JS; пункт ищется по cmpreasonnew_name в загруженном справочнике.
- Жалобы: textarea[name="complaints"].
- Анамнез: textarea[name="anamnez"].
- Диагноз: input[name="diag_id"] только обнаруживается; штатный выбор диагноза пока не реализован.
